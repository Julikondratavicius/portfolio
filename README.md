# julikondratavicius

Portfolio de Julián Kondratavicius, diseñador de producto digital en Rosario, Argentina.

## Desarrollo

```bash
npm install
npm run dev
```

La web usa Next.js, TypeScript y Tailwind CSS. El contenido está en `content/`; los proyectos publicados se registran en `lib/projects.ts`. Las páginas están disponibles en español (`/es`) e inglés (`/en`).

## Publicación

El proyecto se despliega en Vercel desde el repositorio de GitHub de `julikondratavicius`. Los pasos actuales están en [DEPLOY.md](./DEPLOY.md).
